# React Todo Application

[![Live Demo](https://img.shields.io/badge/demo-live-green.svg)](https://to-do-list-eta-drab.vercel.app/)
[![GitHub license](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

A feature-rich Todo application built with React, featuring local storage persistence and a clean, responsive UI.

![Todo App Screenshot](./public/screenshot.png) <!-- Add a screenshot if available -->

## Features

- 📝 Create, read, update, and delete tasks
- 💾 Automatic saving to browser's local storage
- 📱 Fully responsive design
- 📤📥 Import/export functionality
- ✨ Modern UI with Bootstrap 5
- ⚡ Optimized performance
